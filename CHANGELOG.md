### Added

- Initial public packages: `Lumoin.Veritas.Core`, `Lumoin.Veritas.Rdf`, `Lumoin.Veritas.Turtle`,
  `Lumoin.Veritas.NQuads`, `Lumoin.Veritas.Xml`, `Lumoin.Veritas.Canonicalization`,
  `Lumoin.Veritas.Cid`, `Lumoin.Veritas.Sparql`, `Lumoin.Veritas.Shacl`, `Lumoin.Veritas.Skos`,
  `Lumoin.Veritas.Owl`, `Lumoin.Veritas.LinkedData`, `Lumoin.Veritas.JsonLd`,
  `Lumoin.Veritas.JsonPointer`, `Lumoin.Veritas.JsonSchema`, `Lumoin.Veritas.Json`,
  `Lumoin.Veritas.Json.Stj`, `Lumoin.Veritas.Rdf.Json`, `Lumoin.Veritas.Cbor`, and
  `Lumoin.Veritas.CborLd`, plus the `Lumoin.Veritas.Cli` tool (command line, MCP server, and
  SPARQL HTTP endpoint).
- W3C conformance: RDF 1.2 (Turtle, TriG, N-Triples, N-Quads, RDF/XML), RDF Dataset
  Canonicalization (RDFC-1.0), SPARQL 1.2 query and update, SHACL 1.2 Core and SHACL-SPARQL,
  JSON-LD 1.1 (expand, compact, flatten, frame, toRdf, fromRdf), and JSON Schema draft 2020-12
  with all four output formats.
